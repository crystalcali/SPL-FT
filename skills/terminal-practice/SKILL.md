# Terminal practice

Read the task carefully and identify the required output paths and constraints.
Inspect the current directory and relevant files before changing them.
Use small, informative commands to test assumptions. Read actual error output.
Prefer reproducible scripts over a long sequence of manual edits.
After a failure, revise the cause you are testing; do not repeat the same command without a reason.
Keep a short record of the goal, files changed, and checks still needed when the history becomes long.
Run available public checks, inspect resulting artifacts, and verify required paths before declaring completion.
